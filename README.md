# Course Management System
a command line application for students, instructors and admins to keep track of and manage courses effectively. Made for personal learning of OOP.

## Overview
A Java-based Course Management System for managing courses, students, and instructors.  
Supports role-based CRUD operations and persistent data storage using serialization and file I/O.  
Command-Line Interface (CLI) is complete; GUI development is in progress.

## Features
- Role-based functionality for different users (students, instructors, admins)
- Create, Read, Update, Delete (CRUD) operations for courses and users (different levels of permissions)
- To create and keep track of new users
- Persistent storage using Java Serialization (.ser files)
- Test data stored in CSV files for demonstration
- Command-Line Interface for user interaction (log-in, conducting operations)
- GUI version under development

## How to Run
1. Clone the repository.
2. Navigate to the project folders.
3. Compile all java files in 'src/" folder.
4. Run the main class.
5. Ensure csv file of course catalog (an dataset is already included for demonstration) is placed in the "data/" folder. the program will read from these files automatically.
